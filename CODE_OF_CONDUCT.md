# Code of Conduct

Herdr Mods is maintained in spare time. Every comment and pull request lands in someone's inbox, so this page is about keeping things kind, clear and worth reading.

## Be decent

Be respectful and assume good faith. Criticise code and ideas, not people. Harassment, insults, and personal or political attacks aren't welcome anywhere in this project.

## Keep the noise down

- **React instead of commenting "+1" or "any update?".** A 👍 on the issue says the same thing without emailing everyone.
- **Mention people only when you need them.** Every issue and PR is read.
- **Keep this repo's issue numbers out of your fork's commits.** A `#123` or `Fixes #123` in a commit message posts a note on our issue every time that commit is pushed, including each rebase. Put the reference in your pull request's description instead.
- **Push when you're ready.** Each push to an open PR notifies everyone following it, so finish locally, then push.
- **Search before you post,** and post once.

## AI tools

AI tools are welcome here; this project is built with them. What matters is that a person stands behind the work.

- **Say how you used AI.** The PR template asks which tool, and what it did: wrote the code, wrote the tests, helped debug, or nothing. Any answer is fine.
- **Understand your change.** You can explain every line and how it fits the mod, and you've run it.
- **Check AI findings before you report them.** AI tools invent bugs and vulnerabilities that aren't there. Confirm a problem yourself before you open an issue.
- **Answer review comments yourself.** Use an AI to help with the fix if you like, but the reply comes from you.
- **Trim AI writing.** Issues, PRs and comments read best short. Using a translator because English isn't your first language is fine.

## Where this applies

Issues, pull requests, reviews, and commits that reference this repository, including commits on forks.

## What happens

1. The post is hidden, or the pull request closed.
2. A warning, when it looks like an honest mistake.
3. A block from the repository.

Spam, self-promotion, harassment and made-up reports skip straight to a block.

## Reporting

Use GitHub's **Report content** on the post, or [report it to GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
